Near-Instant Compiler Feedback for AI Coding Agents on .NET

  • .NET 10 SDK
  • C#
  • Open Source
  • Apache-2.0
  • Runs Locally

Fuse keeps your solution compiled in memory with Roslyn and checks each edit against it, up to 10.0x faster than dotnet build.

Install the tool:

$ dotnet tool install -g Fuse

In your repository:

$ fuse init

After Every Edit

Up to 10.0x Faster Than dotnet build

The agent gets only the errors its edit introduced, including breaks in other projects.
