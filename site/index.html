Faster .NET Build and Test Loop for AI Coding Agents

  • .NET 10 SDK
  • C#
  • Open Source
  • Apache-2.0
  • Runs Locally

AI agents run dotnet build and dotnet test after every change. Fuse keeps your solution loaded, checks each edit 7.0x to 31.0x faster on open-source repositories, runs only the affected tests, and shows the agent only what it has to fix.

Install the tool:

$ dotnet tool install -g Fuse

In your repository:

$ fuse init

New to Fuse? Getting started shows what it reports.

For Agents and Subagents

What Your Agent Gets

Only new errorsErrors already in the last commit are not reported.
Breaks in other projectsRename a method and every broken caller is listed, with the change that broke it.
Short outputAt most 20 errors or 10 test failures, and one summary line. Nothing when the edit is clean.
One process for all agentsSubagents share it, so the solution is loaded once.
No build clashesBuilds through Fuse take turns, so parallel agents do not break each other's builds.
Safe hooksIf Fuse fails, the hook stays silent and the agent carries on.

The cost is memory: 256 MB to 795 MB in the benchmarks, and more on a machine with more memory. What Fuse costs
