Faster .NET Build and Test Loop for AI Coding Agents

  • .NET 10 SDK
  • C#
  • Open Source
  • Apache-2.0
  • Runs Locally

After every change, AI agents wait for dotnet build and dotnet test. Fuse keeps your solution loaded in memory, checks each edit 8.1x to 27.7x faster and runs only the affected tests.

Install the tool:

$ dotnet tool install -g Fuse

In your repository:

$ fuse init

New to Fuse? Getting started shows what Fuse reports.

Measured Where Agents Struggle

An agent checks again and again, shares the tree with other agents, piles up large changes and runs slow analyzers. Four evals measure each case.

Built for Agents

Features

  • Parallel agents in one working treeAgents that build at once fail on each other's files in obj and bin, so each usually gets its own git worktree. With Fuse they share one working tree and one engine, and their builds take turns: 0 locked-file errors in 60 builds run 3 at a time, and 150 of 150 checks answered with 3 or 4 agents editing at once.Subagents and parallel agents ->
  • Affected testsRuns only the tests the changed code can reach, and skips the rebuild when only .cs files changed.How tests are selected ->
  • Supported agentsClaude Code, Cursor, Codex, Gemini CLI, GitHub Copilot CLI, OpenCode and Muse Code. One fuse init sets up the hooks that check every edit.Connect your agent ->
  • Runs locallyFuse sends no telemetry, makes no network calls of its own, and has no settings to maintain.Privacy and footprint ->
  • Silent when it cannot answerIf Fuse cannot answer, the hook prints nothing and the agent continues. Fuse never edits your code.When Fuse cannot answer ->
