Faster .NET Build and Test Loop for AI Coding Agents

  • .NET 10 SDK
  • C#
  • Open Source
  • Apache-2.0
  • Runs Locally

AI agents wait for dotnet build and dotnet test after every change. Fuse keeps your solution warm and loaded in memory, checks each edit 7.0x to 31.0x faster and runs only the affected tests.

Install the tool:

$ dotnet tool install -g Fuse

In your repository:

$ fuse init

New to Fuse? Getting started shows what it reports.

Features

Parallel agents in one working tree

Subagents edit, check and test the same repository at the same time, without a git worktree each. They share one Fuse engine, so the solution is loaded once, and builds through Fuse take turns, so no build fails on another agent's locked files.

  • 0 locked-file errors in 60 builds run three at a time
  • 150 of 150 checks answered with three or four agents editing at once
