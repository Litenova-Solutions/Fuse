Compiler Feedback for AI Coding Agents

Fuse tells your agent the moment an edit breaks the build, and runs only the tests that change can affect.

$ dotnet tool install -g Fuse

Then run fuse init in your repository. That's the whole setup.

agent  renames Calc.Add to Calc.Plus
fuse   2 new errors: 'Calc' has no 'Add'
         App/Program.cs(2,28)
         Lib.Tests/UnitTest1.cs(4,65)
agent  updates both call sites
fuse   nothing new is broken

What Your Agent Gets

Errors After Every Edit

New compiler errors, including breaks in other projects, right after the edit that caused them.

Only the Tests That Matter

dotnet test runs just the tests the change can reach, and prints only failures.

Silence When All Is Well

A clean edit produces no output, so the agent's context stays small.

Faster Than a Build

Measured against the real dotnet build and dotnet test, with no errors or failing tests missed.
